# Пълен документ — идентификатори

Копирай lib/magistrat-request.ts върху firmi-app/lib/magistrat-request.ts. Това е актуалният файл от master с поправена обработка на ID: приема безопасни цели числа и кодира наклонените черти като %2F. Празни, обектни, контролни и traversal стойности остават забранени. Идентификаторът се пази без премахване или подмяна на символи.

После:

```bash
cd ~/PycharmProjects/api_laws/firmi-app
npm run build && npx wrangler deploy --config dist/server/wrangler.json --name firmi
```

Поправката не променя Stripe, потребителите, администратора или интерфейса. Изпробвана е локално за валидни и невалидни ID и непроменени search маршрути. Точният проблемен запис не е предоставен; ако още има грешка, копирай JSON на конкретния резултат от търсенето, за да се види действителният формат на ID. Реална заявка към Магистрат не е тествана.
