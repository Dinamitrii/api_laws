# Фирмено досие

Просто приложение на български за TheCompanyBook.

## Стартиране

Изисква Node.js 22.13 или по-нов.

```sh
npm run install:ci
npm run dev
```

Отвори адреса, показан при стартиране. В „API настройки“ постави ключ от профила си в https://companybook.bg. Ключът остава само в паметта на страницата; изпраща се до сървъра на приложението и оттам до фиксирания адрес на TheCompanyBook. Не се записва във файл или браузърно хранилище.

## Работа

1. Потърси по име или ЕИК. Показват се първите 20 резултата; уточни търсенето при повече съвпадения.
2. Избери фирма и провери данните. Липсващите стойности могат да се добавят ръчно.
3. Редактирай шаблона или зареди UTF-8 TXT файл. Използвай {{name}}, {{uic}}, {{legalForm}}, {{address}}, {{manager}}, {{email}}, {{phone}}, {{date}}.
4. Изтегли попълнения TXT или избери „Печат / PDF“ и запази като PDF през браузъра.

„Разгледай с примерни данни“ използва измислена фирма и не прави API заявка. Данните и шаблонът се изчистват при презареждане.

Тази версия не попълва съществуващи DOCX или PDF формуляри. Поддържа текстови шаблони и PDF чрез печат. Проверявай резултата преди използване.

API документация: https://companybook.bg/api-docs
