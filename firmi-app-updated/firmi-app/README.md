# Фирмено досие

Просто приложение на български за TheCompanyBook.

## Стартиране

Изисква Node.js 22.13 или по-нов.

```sh
npm run install:ci
npm run dev
```

Отвори `.env.local` в папката на приложението и постави ключа си:

```dotenv
COMPANYBOOK_API_KEY=твоят_ключ
```

Рестартирай приложението след промяна на файла. Ключът се използва на сървъра и не се изпраща към браузъра. `.env.local` е изключен от Git. Локалната среда на Cloudflare зарежда `.env` файловете автоматично; ако има `.dev.vars`, той има предимство и трябва да зададеш ключа там или да премахнеш този файл. При публикуване задай `COMPANYBOOK_API_KEY` като secret на хостинга.

Отвори адреса, показан при стартиране. В „API настройки“ можеш по избор да въведеш друг ключ — той има предимство пред сървърния и остава само в паметта на страницата. Изпраща се до сървъра на приложението и оттам до фиксирания адрес на TheCompanyBook.

## Работа

1. Потърси по име или ЕИК. Показват се първите 20 резултата; уточни търсенето при повече съвпадения.
2. Избери фирма и провери данните. Липсващите стойности могат да се добавят ръчно.
3. Редактирай шаблона или зареди UTF-8 TXT файл. Използвай {{name}}, {{uic}}, {{legalForm}}, {{address}}, {{manager}}, {{email}}, {{phone}}, {{date}}.
4. Изтегли попълнения TXT или избери „Печат / PDF“ и запази като PDF през браузъра.

„Разгледай с примерни данни“ използва измислена фирма и не прави API заявка. Данните и шаблонът се изчистват при презареждане.

Тази версия не попълва съществуващи DOCX или PDF формуляри. Поддържа текстови шаблони и PDF чрез печат. Проверявай резултата преди използване.

API документация: https://companybook.bg/api-docs
