Магистрат — подробни справки и избор на регистър

Основа: Dinamitrii/api_laws, master, commit 508ec9de41ab7a1ffb67a53cd0f8575b61e3661a.
Архивът съдържа само деветте нови/променени файла в firmi-app/, patch и инструкции. Не съдържа API ключове, зависимости или настройки на хостинга.

Прилагане (избери един вариант):
1. При локални промени: копирай magistrat-details.patch в корена на api_laws и изпълни:
   git apply --check magistrat-details.patch
   git apply magistrat-details.patch
   Ако проверката не мине, не презаписвай файловете; съгласувай локалните промени с patch-а.
2. При непроменено копие на посочения commit: разархивирай папката firmi-app/ върху същата папка в проекта. Заменят се четири файла и се добавят пет нови.

След прилагането:
   cd firmi-app
   node tests/magistrat.test.cjs
   npx tsc --noEmit --incremental false
   npm run build
   npm run dev

Нужни са инсталираните зависимости на проекта; нови зависимости няма.
Настрой MAGISTRAT_API_KEY в .env.local или като secret на хостинга. Не го добавяй в Git.

Използване:
- Избери „Магистрат“ от „Източник за търсене“.
- Натисни „Зареди наличните регистри“, избери регистър, текст, период и филтри.
- „Пълен документ“ отваря данните и текста на резултата. Страниците са по 20, 50 или 100 резултата.
- За фирмено досие въведи 9-цифрен ЕИК в „Магистрат · фирмена справка“.
- Досието показва дейност, статус, капитал, управление, собственост, източник и актуалност.
- Историята, обявените актове и съдебните дела се зареждат с отделни заявки. Делата имат страници и подробности за страни, заседания и актове.
- „Зареди във фирмените данни“ прехвърля разширените полета в документа и запазва оригиналната фирмена карта.
- Оригиналните отговори могат да се изтеглят като JSON.

Ограничения:
- Историята връща до 100 промени; има предупреждение при hasMore.
- Делата допускат до 500 страници.
- Обявените фирмени актове се показват според отговора на API; документацията не посочва параметри за странициране на този endpoint.
- Липсващите данни са обозначени, без дописване.

Проверки: TypeScript, production build и шест теста са успешни. Тестовете използват симулирани API отговори. Реални заявки с ключ и интерактивна браузърна проверка не са изпълнени: няма предоставен ключ, а средата не допуска preview сървър.
